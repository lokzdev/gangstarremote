================================================================================
🚀 INSTALAÇÃO DO NOVO PAINEL WEB RAT (React + TypeScript)
================================================================================

📦 PASSO 1: INSTALAR DEPENDÊNCIAS
----------------------------------
cd server/web-app
npm install

⚙️ PASSO 2: RODAR EM DESENVOLVIMENTO
-------------------------------------
npm run dev

# O painel estará em: http://localhost:3000

🏗️ PASSO 3: BUILD PARA PRODUÇÃO
---------------------------------
npm run build

# Os arquivos estarão em: server/web-dist/
